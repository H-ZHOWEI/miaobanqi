# 喵伴启（MiaoBanQi）

智能软件联动启动器。当指定的软件 A 打开时，自动启动你预设的软件/脚本/文件 B，可建立任意多个任务。

## 它能做什么

- **软件联动**：A 从完全关闭到重新打开时自动启动 B、C、D，支持多个动作按顺序执行。
- **仅冷启动触发**：A 已运行时再次点开、切回窗口、产生额外进程都不会误触发 B。支持两种冷启动判定——进程从无到有，或窗口从无到有，因此 Edge、Chrome、微信这类关窗后仍后台常驻的软件也能正常触发。
- **三种触发方式**：进程名、进程完整路径、窗口标题；支持精确 / 包含 / 通配符匹配。
- **运行中程序选择器**：任务管理器风格列表，可搜索、排序、按窗口过滤，选中即填入，无需手打进程名。
- **智能条件**：时间窗口、生效星期、指定进程运行时/不运行时才触发、防抖、冷却、每天一次、定时重复、仅首次触发。
- **五种动作**：启动程序（可带参数/工作目录/管理员权限/隐藏窗口）、打开文件网址、延时等待、结束进程、弹出提醒。
- **常驻后台**：关闭窗口最小化到系统托盘，托盘可暂停监控、检查更新、退出；单实例保护，重复打开只会激活已有窗口，不会堆积多个后台进程和托盘图标。
- **开机自启**：可选，一键开启/关闭。
- **配置管理**：任务导入导出 JSON，配置损坏自动备份。
- **内置更新**：多镜像并发检查、分段并发下载、三重校验、程序内替换、非模态提示，不打断使用。

## 快速开始

1. 双击 `dist/MiaoBanQi.exe` 运行。
2. 点「新建任务」，填写触发条件和动作，保存。
3. 任务自动生效；可在右侧日志看到触发记录。

详见 [操作指引.md](操作指引.md)。

## 典型场景

| 场景 | 触发 | 动作 |
|---|---|---|
| 打开 VS Code 自动起服务 | 进程名 `Code.exe` | 启动 `npm run dev` 的 bat |
| 打游戏自动开语音 | 进程名 `游戏.exe` | 启动语音软件 |
| 打开 Excel 自动开辅助工具 | 进程名 `EXCEL.EXE` | 启动辅助程序 + 延时 + 提醒 |
| 按文档标题触发 | 窗口标题包含 `合同` | 打开模板文件 |
| 上班时间才联动 | 时间窗口 `09:00-18:00` + 工作日 | 任意动作 |

## 技术说明

- Python 3.12 + tkinter + psutil + pystray + Pillow
- 单文件 exe，PyInstaller 打包
- 配置目录：`%USERPROFILE%\.miaobanqi\config.json`
- 监控方式：轮询进程快照 + `EnumWindows` 窗口标题，不注入、不修改被监控软件

## 开发

```bash
# 运行
python main.py

# 测试
python -m unittest discover -s tests -v

# 打包（自动回填 version.json 的 sha256/size）
python build.py
```
